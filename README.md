# Насколько хорошо ты меня знаешь?

Отдельный сайт с двумя тестами по 15 вопросов: «Для неё» — о нём, «Для него» — о ней. В каждом вопросе четыре варианта и один правильный ответ.

Вопросы основаны на приложенном пользователем тексте. В её тесте вопросы о падении, минах, переживаниях из-за роста, прошлом опыте отношений и распознавании лжи заменены спокойными вопросами об увлечениях и спорте. Для сохранения 15 вопросов некоторые известные факты проверяются с разных сторон; новые биографические сведения не добавлены.

Один вопрос показывается на одном экране. Можно менять ответы, возвращаться назад и пропускать вопросы. Правильные ответы открываются после завершения. Ошибки и пропуски считаются отдельно, процент округляется до целого числа. Повторное прохождение очищает только выбранный тест. Незавершённые попытки и порядок вариантов сохраняются в sessionStorage в текущем сеансе браузера.

## Локальный запуск

```sh
npm start
```

Открыть `http://127.0.0.1:4175`.

```sh
npm test
```

Статические файлы сайта находятся в `dist/`; сборка и установка зависимостей для запуска не требуются.

Шрифты включены в формате WOFF2. Анимации выполняются средствами CSS и отключаются при системной настройке уменьшения движения.

## Проверка

Модульные проверки покрывают два набора вопросов, правильные/неправильные/смешанные ответы, отдельный подсчёт пропусков, округление процентов и проверку сохранённых попыток.

Вёрстка проверяется в Chromium на размерах iPhone XS и iPhone 13 Pro, в портретной и горизонтальной ориентации, включая уменьшенную доступную высоту экрана. Это эмуляция размеров, а не проверка на физических iPhone и Safari с реальными панелями браузера.

Необязательные WebMCP-инструменты используют feature detection. В текущей среде реальный поддерживаемый WebMCP-контекст недоступен, поэтому их совместимость с реализацией браузерного стандарта не подтверждена.

Sites создаёт приватную публикацию. Доступ для другого человека нужно настраивать средствами хостинга.
